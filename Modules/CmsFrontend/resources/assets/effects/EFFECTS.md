# Danh mục effect

Thư mục: `Modules/CmsFrontend/resources/assets/effects/`. Mọi đường dẫn bên dưới tính từ đây. Effect không chứa tên/màu theme; hook HTML và thông số do theme truyền vào (options) hoặc đặt bằng biến CSS.
Dùng chung `core/effect-utils.js` (`clamp`, `easeOutCubic`, `markOnce`, `onScrollFrame`) và `core/reduced-motion.js` (`prefersReducedMotion`). Khởi tạo lại không tạo trùng listener/timer.

## Quy ước
- Trang chủ dựng theo Homepage Layout Manager: mỗi cụm khai báo KEY preset (`Homepage/EffectCatalog.php`); trang chỉ nạp entry của preset mà cụm đang bật khai báo (`$homepageEffectEntries` -> `@vite` trong `home.blade.php` của theme). Entry tự khởi chạy nằm ở `effects/auto/` (`reveal.js` khởi tạo cả stagger và count-up, `crossfade-slider.js`, `gallery-orbit.js`). Hành vi riêng của theme (hero-slider, scroll-spy, rail, hiệu ứng Ban Đề án) vẫn ở `js/screens/<theme>/theme.js`. `shell.js` không khởi tạo effect.
- Hook HTML trong bảng là mặc định hiện có; effect có `options.hooks`/tên thuộc tính để theme đổi.
- Reduce Motion: `reveal`/`stagger` vẫn chạy khi máy bật giảm chuyển động (quyết định đã chốt, CSS dùng `!important` để vượt luật `transition:none` của theme); `crossfade-slider` không tự chạy; auth bỏ hoạt ảnh và điều hướng ngay; `gallery-orbit` giữ hành vi cũ (không xét).
- Effect thuộc khung dùng chung: `scripts/theme-profiles.mjs` (`sharedEffectEntries`) đóng gói CSS của reveal, stagger, gallery-orbit, crossfade-slider và `effects/auto/*.js` trong MỌI profile (kể cả build một theme); `effects/auth/*` cũng là entry chung.
- CSS effect chỉ chứa cơ chế chuyển động; màu, cỡ, bố cục ở lại CSS theme. Effect CSS phải nạp SAU CSS theme.
